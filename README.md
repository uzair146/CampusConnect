# CampusConnect 🎓
### Student Management System

A console-based student management system developed in C++ as a two-member team project for the Programming Fundamentals course.

## 📌 About the Project

CampusConnect is a simple academic management system designed to organize student records and academic performance. It provides separate interfaces for administrators, teachers, and students to manage and access academic information.

The project demonstrates the practical use of fundamental programming concepts through a real-world academic management scenario.

## ✨ Features

### 👨‍💼 Admin Portal
- Add and delete student records.
- Manage teacher records.
- Organize student and teacher information.

### 👨‍🏫 Teacher Portal
- Enter and manage student marks.
- Manage quizzes, assignments, sessional exams, and final exams.
- View student academic performance.
- Identify students who have passed.

### 🎓 Student Portal
- View academic grades.
- Check CGPA and academic results.
- Access subject-wise performance.

## 🛠️ Technologies Used

- C++
- Object-oriented programming fundamentals
- Functions and modular programming
- File handling using text files
- Conditional statements and loops

## 🚀 Getting Started

### Prerequisites

- Microsoft Visual Studio or any compatible C++ compiler.
- Basic knowledge of running C++ console applications.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/CampusConnect-Student-Management.git
   ```

2. Open the project folder in Visual Studio.
3. Open `Code.cpp` and build the project.
4. Run the application to access the main menu.

## 💻 How to Use

1. Launch the application.
2. Select Admin, Teacher, or Student from the main menu.
3. Follow the on-screen instructions to manage or view academic records.
4. Select Exit to close the application.
